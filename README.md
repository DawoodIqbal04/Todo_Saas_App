# 🚀 In-Memory CLI Todo App

A simple yet powerful command-line interface (CLI) Todo application built with Python. This app allows you to manage your tasks efficiently right from your terminal!

## ✨ Features

-   **Add Tasks**: Quickly add new tasks with title and an optional description.
-   **Unique Short IDs**: Tasks are assigned a unique, short 4-character ID for easy reference.
-   **List Tasks**: View all your tasks with clear indicators for their completion status.
-   **Update Tasks**: Modify existing task titles or descriptions.
-   **Delete Tasks**: Remove tasks by their unique ID.
-   **Toggle Status**: Mark tasks as complete or incomplete.
-   **In-Memory Storage**: All data is stored in memory, providing a fresh start with every launch. (Perfect for quick, transient task management!)
-   **Intuitive CLI**: A user-friendly command-line interface with clear prompts and messages.

## 🛠️ Tech Stack

-   **Python 3.13+**: The core language powering the application. 🐍
-   **UV**: A fast Python package installer and runner, ensuring a smooth development and execution experience. ⚡
-   **In-Memory Data Storage**: Tasks are managed in memory, offering simplicity and speed. 🧠

## 🤖 Built with AI

This project was meticulously designed and implemented using **SpecKit Plus** and **Gemini Cli**! Leveraging AI for specification, planning, and task breakdown, this application showcases the power of intelligent development workflows. 🌟

## 🏃‍♀️ Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/DawoodIqbal04/Todo_Saas_App.git
    cd Todo_Saas_App
    ```

2.  **Run the application**:
    Ensure you have `uv` installed (`pip install uv`).
    ```bash
    uv run -m todo_app.main
    ```

## 👨‍💻 Usage

Once the application is running, you'll see a menu with options. Follow the prompts to manage your tasks:

```
--- Todo App ---
1. Add a new task
2. List all tasks
3. Update a task
4. Delete a task
5. Mark a task as complete
6. Mark a task as incomplete
7. Exit
----------------
Enter your choice:
```
