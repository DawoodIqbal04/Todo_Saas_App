# Quickstart: In-Memory CLI Todo App

This guide explains how to run the CLI Todo application.

## Prerequisites

- Python 3.13+
- `uv` installed (`pip install uv`)

## Running the Application

1.  **Navigate to the project directory**:
    ```bash
    cd GIAIC_Hackathon_02
    ```

2.  **Run the application using `uv`**:
    ```bash
    uv run todo_app/main.py
    ```

3.  **Use the application**:
    Once the application is running, you will see a command prompt. You can use the following commands:
    - `add`: Add a new task.
    - `list`: List all tasks.
    - `update`: Update an existing task.
    - `delete`: Delete a task.
    - `complete`: Mark a task as complete.
    - `incomplete`: Mark a task as incomplete.
    - `exit`: Exit the application.
